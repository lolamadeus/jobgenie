# Lead sweep

1. Check `knowledge/preferences.md`. If `tracks` doesn't include `freelance`, ask whether the user
   wants to add a freelance track first (and capture services, targets and rates if so).
2. Read the freelance plan and lead sources in `knowledge/strategy.md`.
3. Follow "Finding freelance leads" in `docs/workflows.md`: job boards and "hiring" posts, plus
   cold targets showing a clear need. Record each as `pipeline/leads/slug.md` with the **signal**.
4. Follow up on leads whose `next_date` is due.
5. Draft short, specific outreach for the best new leads. **Nothing is sent without the user's
   approval of the exact text.**
6. Report, update "Current state" in `CLAUDE.md`, and log the sweep.
