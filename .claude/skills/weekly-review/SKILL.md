# Weekly review

Follow "Weekly review" in `docs/workflows.md`:

1. Read the last 7 days of `log/`, and every application and lead with activity or a `next_date`
   in the next 7 days.
2. Summarise for the user: applications sent, replies, interviews, rejections, new leads; what's
   overdue; what's due this week (with drafts ready for any follow-ups).
3. Look for patterns: which sources and role families are producing interviews, which aren't.
   Propose changes to `knowledge/strategy.md` and make the ones the user agrees to.
4. Work through a few open questions from `knowledge/open-questions.md` if the user has time.
5. Refresh "Current state" in `CLAUDE.md` and log the review.
